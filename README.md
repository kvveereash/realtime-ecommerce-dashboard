# Food Delivery Ecommerce Website

A modern full-stack Food Delivery Ecommerce Website built using the MERN Stack with Stripe payments, real-time order tracking, coupon system, admin dashboard, and responsive premium UI.

---

# Features

## User Features

- User Authentication (JWT)
- Register & Login
- Browse Food Products
- Add to Cart
- Quantity Increase / Decrease
- Remove from Cart
- Coupon System
- Stripe Payment Integration
- Delivery / Pickup Option
- Checkout System
- Order History
- Real-Time Order Updates
- Responsive UI

---

## Admin Features

- Admin Dashboard
- View All Orders
- Update Order Status
- Real-Time New Order Notifications
- Product Stock Management
- Coupon Management

---

# Tech Stack

## Frontend
- React.js
- React Router DOM
- CSS3
- Context API
- React Toastify
- Socket.io Client
- Stripe React SDK

---

## Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- Socket.io
- Stripe API
